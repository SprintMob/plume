Plume

Hold a key, speak, release. The text is at your cursor in under 500 ms, and the audio never left the Mac.

macOS 14+ · Apple Silicon. The recommended speech model downloads about 461 MB on first setup. A signed browser download is not available yet.

What it is

A dictation daemon that lives in the menu bar. Hold fn, talk, let go, and the transcript is typed where your cursor is. Double-tap to keep recording without holding.

Transcription happens on this Mac. There is no account, no API key and no speech sent to a server, because the model runs on the Apple Neural Engine. No transcript is written to disk, ever: the session history is in memory and dies with the process.

The app is 7 MB. It has one key, and the settings window exposes nothing the daemon could not already do.

Honestly

The current v0.1.0 release is ad hoc and is not notarized. A browser download is blocked by Gatekeeper; the CLI installer above remains the supported path. Each ad-hoc update needs a new Accessibility grant. Read the details.

Most of the code was written by people who opened pull requests against the project this forks and never got a review. They are named in the NOTICE.
